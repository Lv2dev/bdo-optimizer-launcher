## 변경 사항
- 장시간 실행하거나 재부팅한 뒤 트레이 아이콘이 응답하지 않거나 사라지는 문제를 개선했습니다.
- 성능 모니터 그래프가 새 데이터를 오른쪽에서 왼쪽으로 자연스럽게 보여 주도록 수정했습니다.
- 업데이트를 Release 페이지에서 직접 내려받지 않고 앱 안에서 다운로드하고 서명을 확인한 뒤 설치할 수 있게 했습니다.
- 스크롤바가 표시되는 화면에서도 콘텐츠가 창 중앙에 보이도록 정렬을 수정했습니다.
- README 첫 화면에 실제 앱 화면과 탭별 기능을 보여 주는 제품 둘러보기를 추가했습니다.
- 이번 버전은 기존 0.2.0에서 설치 프로그램으로 한 번 업데이트해야 하며, 다음 버전부터 앱 안 업데이트를 사용할 수 있습니다.
